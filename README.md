#  Mini Casino

##  Présentation
Projet de mini casino virtuel jouable en local, utilisant des jetons fictifs pour miser et gagner.

##  Les jeux
-  **Bandit manchot** : aligner trois motifs identiques.
-  **Roulette** : miser sur un résultat.
-  **Blackjack modifié** : se rapprocher de 21 sans le dépasser.

##  Fonctionnalités
- Menu principal : choix de la mise et du jeu.
- Gestion des jetons, des mises et des gains.
- Interface graphique créée avec du code.
- Sauvegarde des données si possible.

##  Objectif
Développer un casino virtuel dans le cadre d'un projet de groupe, en utilisant GitHub pour collaborer et présenter notre travail.

**Aucun argent réel n'est utilisé.**
